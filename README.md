# Fitbit Calorie Burn Prediction & Workout Pattern Clustering

This project uses Machine Learning on Fitbit fitness tracker data to:
1. **Predict Calories Burned** during a workout session (Regression)
2. **Discover workout patterns** by grouping similar workouts together (Clustering)

## How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Add the dataset
raw_data/Fitbit_dataset.csv


### 3. Run the full pipeline
```bash
python main.py
```
This runs EDA, trains and compares regression models, tunes the best one,
then runs clustering — saving all charts to `reports/figures/` and trained
models to `models/`.

### 4. Try the web app
```bash
streamlit run app.py
```
Enter workout details in the browser and get a live calorie burn prediction.

## Task 1 — Regression (Calorie Burn Prediction)

**Goal:** Predict `Calories_Burned` from workout and body metrics.

**Steps:**
- Handle missing values, cap outliers (IQR method)
- Encode categorical columns (Gender, Workout_Type, Experience_Level)
- Scale numeric features (StandardScaler)
- Train-test split (80/20)
- Compare 8 models: Linear Regression, Ridge, Lasso, KNN, Decision Tree,
  Random Forest, SVR, XGBoost
- Evaluate using MAE, RMSE, R², and 5-fold cross-validation
- Tune the best model with GridSearchCV

**Note:** The raw dataset also includes `Base_MET`, `HR_Intensity`, and
`Effective_MET` columns. These are dropped during preprocessing because
they were used to calculate `Calories_Burned` in the first place — keeping
them would be data leakage.

**Result:** R² ≈ 0.999 (target was R² ≥ 0.80)

---

## Task 2 — Clustering (Workout Pattern Discovery)

**Goal:** Group similar workouts together without using labels.

**Steps:**
- `Workout_Type` and `Calories_Burned` are **not** used as features
  (unsupervised — no labels allowed during training)
- Encode + scale remaining features
- Reduce dimensions with PCA (for visualization)
- Find the best number of clusters (K) using the Elbow Method + Silhouette Score
- Cluster with KMeans (main method)
- Compare against Hierarchical Clustering and DBSCAN
- Interpret clusters by cross-tabulating with `Workout_Type` (for insight only)

**Result:** Silhouette Score ≈ 0.41 (target was ≥ 0.15)
